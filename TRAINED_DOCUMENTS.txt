Where the code is:  export_docs.py (known layouts, READERS list)  |  plugins\*.py shipped with the server  |  readers.py (any other invoice / packing list /
air waybill)  |  danfoss_docs.py, festo_docs.py, agilent_engine.py, msd_engine.py, jfood_server_engine.py (own tools)
|  plugins: PERMIT_SERVER_DATA\plugins\*.py (added later without rebuilding).
New job: no supplier list - the tool / reader is ALWAYS chosen from the document layout (also when PDFs are added later).
Inside "Any supplier" the layout is recognised from the text of each file.

HS LISTS BY DESCRIPTION (Settings > Product masters): PANASONIC FACTORY built in - items without an HS get the HS of the
same / nearest description (nearest = CHECK), nothing near -> empty. Upload a new version on the server any time.

CUSTOMER RULES (job > Requirements > Customer rules): the rules of the customers found in the documents are listed after
reading, all ticked = used; untick one you do not need for that job (items worked out again at once; Validate shows
"Customer rules: n used, n unticked"). Customers with rules: SANDVIK, DOW CHEMICAL PACIFIC, RS COMPONENTS (permit_engine.CUSTOMER_RULES).

RULES FOR EVERY LAYOUT
- Export permit = export fields only, import permit = import fields only (Exporter / Outward / Out / Departure /
  Discharge / Consignee / CO  vs  Importer / Inward / In / Arrival). Export date = ETD / ATD / shipped on board;
  import date = ETA / ATA.
- HS code typed by the user -> HS UOM + HS qty worked out again (10 digits -> 8).
- Brand from the documents; none -> user picks UNBRANDED / a brand once (remembered per supplier); document brands stay.
- Same invoice / packing list added twice is used once. Scanned PDFs: OCR, sideways pages turned automatically.
- Never a guessed value: blank + CHECK note, listed on Validate and in CHECK_REPORT.xlsx.

TRAINING A NEW DOCUMENT (in another chat)
  Attach: the sample documents (PDF / Excel), UPDATE_HS_CODE.xlsx, the OUTPUT FILE (dec-upload Excel) and this file.
  Prompt:
    "This is my PERMIT SERVER (Singapore TradeNet permits). TRAINED_DOCUMENTS.txt lists what it already reads.
     Write a plugin .py from PLUGIN_TEMPLATE.py for the attached <supplier> documents: invoice no / date, items
     (item no, description, qty, UOM, price, amount, HS, COO, brand), net / gross weight, packages, HAWB / MAWB,
     ports, dates. <IMPORT or EXPORT>. Rules: <e.g. value = ..., description = ...>. Never guess - leave blank +
     note. Test it on every sample and show the totals against the invoice."
  Then Settings > Suppliers and readers > Add plugin (.py) on the server PC, "Test a PDF", and add the layout here.
